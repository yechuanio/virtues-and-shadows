# 明与暗 · 五大家族与结果页主题方案

2026-10-26 · 野川 yechuan · github.com/yechuanio

用户已确认全系列沿用样图画风，提灯渡人者、赤焰破阵者、昼夜织锦者三张样图直接使用。本稿整理五类视觉家族与后续页面主题，不修改现有网站。

五类是视觉和叙事上的归组，不是新增心理测量维度，不参与原始14项得分，不表示优劣。每种人格只归属一个家族。家族代表共同的关注方向，不能替代每个人格的具体解释。

## 1. 灯火之庭 / The Lantern Court

- 主旋律：关怀 · 分享 · 信任
- 成员：提灯渡人者、金穗播种者、月桂守誓者
- 共同意象：像被点亮的小庭院，让靠近与共同成长成为主旋律。
- 装饰：枝叶、月桂、麦穗与温暖灯光。
- 配色：纸色 #F7F3E8；正文 #29483C；主色 #4E7052；点缀 #B38B48。

## 2. 山岳之垒 / The Mountain Bastion

- 主旋律：耐心 · 建造 · 秩序
- 成员：磐石守望者、星火筑城者、天平执衡者
- 共同意象：像沿山而建的石城，强调稳定节奏、持续推进和合适的限度。
- 装饰：山脊、石拱、阶梯、松枝与简洁对称纹样。
- 配色：纸色 #F3F2EB；正文 #34473E；主色 #667467；点缀 #A58B60。

## 3. 日冕之城 / The Solar Citadel

- 主旋律：位置 · 力量 · 资源
- 成员：烈日加冕者、赤焰破阵者、鎏金藏星者
- 共同意象：像晚霞中的城垣，关注自己的分量、对阻碍的反应和想要留住的事物。
- 装饰：日轮、城拱、铜金细线、枫叶与克制的火纹。
- 配色：纸色 #F7F0E5；正文 #56392E；主色 #A4583D；点缀 #B58B46。

## 4. 镜月之湾 / The Moonlit Cove

- 主旋律：回响 · 期待 · 满足
- 成员：镜湖逐光者、蜜宴寻慰者、绯月逐魅者
- 共同意象：像月光照映的水湾，容纳外界回响、即时体验、比较与亲近带来的牵引。
- 装饰：月弧、水纹、倒影、花瓣与柔和的杯盏轮廓。
- 配色：纸色 #F4F0EC；正文 #3D4055；主色 #6F738D；点缀 #9A6674。

## 5. 云岚之境 / The Mistlands

- 主旋律：观察 · 留白 · 多面
- 成员：空谷听风者、云端卧梦者、昼夜织锦者
- 共同意象：像尚有余白的山间地图。接纳新视角、启动前的停驻和多维接近，分别以不同方式呈现开放的可能。
- 装饰：流云、风纹、细密经纬、远山与疏朗星点。
- 配色：纸色 #F3F3EE；正文 #3C4D4B；主色 #7A9693；点缀 #A7A0B2。

## 结果页的使用方式

1. 结果页由主要人格所属家族决定整页的主色、页角纹样、标题饰线与氛围。保留浅纸底与深色正文，提高可读性；背景装饰保持轻淡。
2. 主人格展示“家族名 → 人格中英文名 → 人格插画 → 对应描述与建议”。家族名为辅助标识，人物本身仍是视觉中心。
3. 同一类内，用每个人格自己的象征物区分，如灯、种子与契约；不把同一张背景和同一种姿态简单换色复制给所有成员。
4. 备选人格卡片只使用自身家族的小色标与局部边框，不把三种整页主题叠加。导出结果图沿用主人格家族的装饰。
5. 人格介绍或结果查询中切换浏览某个原型时，详情区域跟随所浏览原型的家族；不得因浏览动作覆盖用户本人的测试结论。
6. 答题页继续保持中性视觉，不提前显示家族倾向或人格匹配，避免边答边追逐某类结果。
7. 所有家族的图片面积、装饰精细度、文字层级和卡片规格一致。没有高低等级、稀有度奖章、战力数值或善恶阵营。
8. 云岚之境的三个原型分别关注倾听、启动阻力及分布多面，归类只取“视角与可能”的共同意象；不据此宣称行动回避意味着想象力，也不宣称均衡意味着全能。
9. “主旋律”在本方案中指页面视觉与叙事主题，不增加自动播放音乐。
