# 明与暗 · 七美德与七宗罪自测

由 **野川 yechuan** 制作的中文自我观察网页：98 道简单选择题、14 个独立维度，完成后生成雷达图和分项得分。

- 在线体验：[明与暗](https://virtues-and-shadows-98.peppyvale17.chatgpt.site)
- GitHub 主页：[yechuanio](https://github.com/yechuanio)
- 源码仓库：[yechuanio/virtues-and-shadows](https://github.com/yechuanio/virtues-and-shadows)

## 功能

- 共 98 题，分 7 组；14 个维度各 7 题，题目交错呈现。
- 四个统一频率选项，并支持“不适用 / 跳过”。
- 自动保存浏览器本地进度，可暂停、续答和修改。
- 七美德与七宗罪独立计分，生成两张雷达图和 14 项分数。
- 支持下载 PNG / SVG 结果图，以及浏览器打印 / 另存为 PDF。
- 适配电脑和手机，支持键盘操作。
- 页面不上传作答，不需要姓名，不调用外部分析服务。

## 使用

下载仓库，使用现代浏览器打开 `index.html` 即可，无需安装依赖或构建。也可以把仓库根目录部署到静态网站托管服务。

本地进度保存在当前浏览器中；清理浏览器数据、更换设备或更换网站域名后，不会自动迁移。共用设备使用后可点击“清除作答”。

## 维度与计分

七美德：谦逊、仁爱、耐心、勤勉、慷慨、节制、贞洁（此处侧重亲密互动中的尊重、自愿与边界）。

七宗罪：傲慢、嫉妒、暴怒、懒惰、贪婪、暴食、色欲（此处关注具体行为、失控及生活影响）。

四个频率选项记 0、1、2、3 分，反向题按 3、2、1、0 分计。“不适用 / 跳过”不计入分母。每个维度至少 5 道有效回答才显示得分。

```text
维度得分 = 有效题调整后总分 ÷ (3 × 有效题数) × 100
```

结果四舍五入为整数。信息不足的维度在图表中保留缺口，不按 0 分处理。两组分别计分，不计算“道德总分”。完整题目和反向题号见 [题目与计分说明](题目与计分说明.md)。

## 项目文件

- `index.html`：包含题库、界面、计分、图表与导出功能的独立网页。
- `题目与计分说明.md`：全部 98 题、维度对应及计分方式。

## 使用范围

这是原创的非标准化自述问卷，未经过信效度验证，没有人群常模或临床分界线。结果仅供自我观察，不代表人格定论、心理诊断或道德等级。正常休息、饮食享受和性欲本身无需被评判。
